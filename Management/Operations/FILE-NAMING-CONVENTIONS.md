# File Naming Conventions

- Use ISO dates: `YYYY-MM-DD`.
- Name update directories by publication date, not by the start date of the coverage window.
- Use descriptive, stable Markdown filenames for reports.
- Use hyphens between words and avoid ambiguous abbreviations.
- Include the reporting period in the update metadata, not only in the filename.
- Do not encode the provider name into the stable `Provider` directory name.
- Keep file names stable after publication; corrections should be explicit and dated.
