# Updates

This is the chronological record of research updates produced by the repository's providers.

## Structure

`Updates/Provider/YYYY-MM-DD/Data/`

- `Provider` is a stable directory name. The actual provider identity is recorded in the provider and update metadata files, not encoded into the directory name.
- Each date directory is named for the date the update was published.
- `Data` contains only information actually discovered and considered material for that reporting interval. It is deliberately dynamic.

## Dynamic data rules

1. Do not create empty company, industry, report, or source folders just to match a fixed taxonomy.
2. Create a topic directory only when the update contains material information for that topic.
3. A company absent from a period's data is not assumed to have had no news; it means no material item was included in that update.
4. Add new companies, technologies, sectors, or themes whenever evidence makes them relevant.
5. Keep each update self-contained, dated, sourced, and explicit about its coverage window.
6. Do not silently alter a published update. Add a correction or a superseding update with a link to the original.

The topic taxonomy is guidance for organizing real findings, not a folder template that must be copied into every update.
